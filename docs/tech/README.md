# EvalForge 技术方案总览

> 适用版本：Demo V0.2.0 | 对应 BRD：V1.2 | 最后更新：2026-07-24

## 平台定位

本平台是一个**评测集自动化生成系统**。核心链路：

```
上传文档 → 解析Block → 抽取EIU → 覆盖规划 → 生成题目+答案+证据 → 质量门禁 → 导出评测集
```

**不是 RAG 问答系统**。检索（向量/关键词/关系索引）是辅助工具，用于 EIU 抽取和跨段发现，不是平台产出物。

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Python + FastAPI |
| 数据库 | SQLite（Demo） |
| 存储 | 本地文件系统（Demo） |
| 向量索引 | FAISS（辅助） |
| Embedding | BGE-small-zh-v1.5 |
| LLM | 可配置（OpenAI 兼容 API） |
| 前端 | 管理台风格静态页面 |

## Demo 阶段全局边界

**必做：**
- 文档上传解析 + EIU 抽取（LLM 单通道） + 覆盖清单
- 单段题目生成 + 标准答案 + 证据绑定
- 4 项基础质量校验 + 覆盖率计算
- 版本冻结 + JSON/JSONL 导出
- 业务需求书→测试功能点（EIU 提取，无答案）
- 智能问答 Chat 占位

**不做：**
- 跨段/跨文档题目、改写/反例
- EIU 双通道校验、治理审核 Skill（S0 规则）
- 调用待测系统评测、失败归因
- 增量更新、表述替换泛化、评测集回流
- 完整智能问答交互

## 核心数据实体关系

```
corpus（语料库）
  ├── document（原始文档）
  │     └── block（结构化段落/表格行）
  ├── eiu（可评测信息单元）
  │     └── eval_case（评测样本：题目+答案+证据）
  ├── coverage_report（覆盖报告）
  ├── quality_check_result（质量校验结果）
  └── dataset_version（评测集版本）
```
