## 2. 技术方案概览

### 2.1 对话架构

```
用户输入（文本/文件）
    │
    ▼
[意图解析]
    ├── 意图分类：upload / preview / edit / ask / config / task
    ├── 参数提取：文档名/样本ID/EIU ID/过滤条件
    │
    ▼
[业务路由]
    ├── upload → 文档上传模块
    ├── preview → 构建预览卡片数据
    ├── edit → 调用 CASE API 执行编辑
    ├── ask → 检索编排 + LLM 回答
    │
    ▼
[响应构建]
    ├── 文本消息（text）
    ├── 文档卡片（document_card，含缩略信息和操作入口）
    ├── 预览卡片（preview_card，可滚动内容面板）
    ├── 任务进度卡片（task_progress，含进度条）
    └── 确认卡片（confirm_card，含操作按钮）
```

### 2.2 对话消息类型

| 消息类型 | 内容结构 | 前端渲染 |
|---|---|---|
| text | `{text: "..."}` | 标准文本气泡 |
| document_card | `{file_name, file_size, parse_status, actions: [...]}` | 文档信息卡，可点击查看详情 |
| preview_card | `{title, items: [...], scrollable: true}` | 可滚动预览面板 |
| task_progress | `{task_id, status, progress_pct, message}` | 进度条卡片 |
| confirm_card | `{message, actions: [{label, action, style}]}` | 确认/取消按钮组 |

### 2.4 对话意图解析

```python
class IntentParser:
    """将用户输入解析为意图+参数。"""

    def parse(self, text: str, context: ChatContext) -> Intent:
        """
        LLM prompt:
          "你是 EvalForge 平台的对话意图解析器。

           {
             intent: upload|preview|edit|ask|config|task|unknown,
             params: { ... },

             clarification_needed: null 或 "需要用户补充的信息"
```

### 2.5 与现有模块的关系

智能问答不是独立模块，而是对现有模块的对话式入口：

| 现有模块 | 对话交互方式 |
|---|---|
| 语料库与文档接入 | FR-CHAT-001 对话上传 |
| 文档解析 | 对话反馈解析进度 |
| EIU 抽取 | 对话触发 + 预览 EIU 清单 |
| 评测集生成 | 对话触发 + 展示进度 |
| 检索与问答 | FR-CHAT-004 对话提问 |
| 评测集编辑 | FR-CHAT-003 对话修改 |
| 覆盖率查看 | 对话查询统计 |
| 导出 | 对话触发导出 |
| 需求书→测试功能点 | 对话发起 + 预览结果 |
