# Architecture

本文件描述系统的模块划分、数据流和运行方式。

## 平台定位

本平台是一个**评测集平台（EvalForge）**：以 EIU 为连接知识库、评测集生成与评测质量控制的中间层，统一管理**文档生成评测集、直接上传评测集、公共评测集库**三类来源（BRD V1.3 §8.22），从文档中自动抽取知识点（EIU）并生成可评测的问答对（或导出知识点本身）。EIU 是向量化与跨文档知识融合的核心对象（chunk/Block 为中间结构，主要服务检索）。

核心链路：

```
上传文档 → 解析Block → 抽取EIU（规则分类+LLM，含上下文补全预留） → EIU向量化（FAISS）
→ 覆盖规划 → 生成问答对/导出知识点（证据绑定） → 质量门禁（量化评估+审核） → 版本冻结/评测集组合 → 导出
```

## 系统架构（四层）

1. **接入层**：前端管理台页面、HTTP API（FastAPI）
2. **业务层**：文档解析、EIU 抽取、题目生成、质量校验、版本管理、导出
3. **数据层**：MySQL（docker evalforge 库）、MinIO（原始文件）、FAISS（EIU 向量为主）
4. **模型层**：BGE embedding（语义分段 + EIU/Block 向量化）、LLM（EIU 抽取 + 题目/答案生成 + 质量校验）

## 核心模块（7 个）

| 模块 | 职责 | Demo 状态 |
|---|---|---|
| 01-数据基础 | 语料库管理、文档上传/解析（版面感知 + BGE 语义分段）、Block 存储、EIU 向量化（FAISS 核心对象）、文档更新 job 进度 | 必做 |
| 02-EIU 抽取与覆盖规划 | 规则分类 + LLM 单通道 EIU 抽取（10 种类型 + 8 条拆分规则，P0 以确定性规则为主）、覆盖清单、加权覆盖率计算、实质 Block 对账 | 必做 |
| 03-评测集生成 | 单段题目+答案+证据绑定生成、两种输出模式（知识点 / 问答对）、泛化扩写 | 必做 |
| 04-质量门禁与治理审核 | 5 项基础质量校验（可回答性/忠实性/唯一性/证据充分性/问题相关性）、量化质量评估参考评分（BRD V1.3 FR-QA-005，预留）、S0 硬门禁（延后）、审核状态机 | 必做 |
| 05-数据集生命周期 | 版本冻结/导出（JSONL/JSON/Excel）、目录树浏览、表格视图+可视化、手动编辑、无问题提示；三类来源统一管理与评测集组合选择（BRD V1.3 §8.22，预留） | 必做 |
| 07-智能问答交互 | 对话式平台操作入口（上传/预览/编辑/问答）、意图解析、多轮对话 | Demo 不做 |

## 数据流

1. 文档上传 → 本地 `storage/raw/` + SQLite 元数据
2. 文档解析 → 版面感知（PyMuPDF/python-docx）+ BGE 语义分段 → Block + 原文定位
3. Block → BGE Embedding → FAISS 索引（辅助用途：检索、去重提醒、跨段候选发现）
4. EIU 抽取 → 规则分类 + LLM 逐 Block 抽取可评测信息单元（P0 以确定性规则为主）→ `eiu` 表（含 `embedding_vector`）
5. EIU → BGE Embedding → EIU FAISS 索引（EIU 为向量化核心对象，用于抽取去重与未来跨块/跨文档候选）
6. 覆盖规划 → 确定性代码计算加权覆盖率 → `coverage_report`（仅适用文档生成评测集）
7. 题目生成 → LLM 基于 EIU 生成题目+答案+证据绑定（继承 EIU 证据列表，预留）→ `eval_case` 表
8. 质量校验 → LLM 5 项检查 → `quality_check_result` 表；量化质量评估参考评分（BRD V1.3 FR-QA-005，预留）
9. 导出 → JSONL / JSON / Excel → 评测集交付物

## 两种输出模式

| 模式 | 输入 | 产出 | Demo |
|---|---|---|---|
| A — 文档知识点 | EIU 表 | EIU 自然语言陈述 + 章节/证据定位，不含题目与答案 | 必做 |
| B — 问答对 | EIU + LLM 生成（或用户上传种子问答对） | 规范问答对 + 泛化扩写，含题目/答案/证据绑定 | 必做 |

## 存储体系（Demo 简化）

| 存储层 | Demo 实现 | 生产迁移 |
|---|---|---|
| 原始文件 | MinIO（docker，落盘 `storage/raw/`） | MinIO/对象存储 |
| 关系型数据 | MySQL（docker evalforge 库） | PostgreSQL/云数据库 |
| 向量索引 | FAISS 本地文件（EIU 向量为主） | 向量数据库 |
| 语义理解 | MySQL（EIU 表及其他语义表，含 `embedding_vector`） | PostgreSQL |
| 配置与版本 | 环境变量 + 代码内 Prompt 模板 | 配置中心 |
