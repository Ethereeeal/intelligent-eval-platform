# Architecture

本文件描述系统的模块划分、数据流和运行方式。

## 系统架构（四层）

1. **接入层**：前端管理台页面、智能问答对话界面（Demo 占位）、HTTP API
2. **业务层**：文档管理、评测集生成、任务流、检索编排、结果聚合、EIU 提取
3. **数据层**：MySQL、MinIO、FAISS
4. **模型层**：BGE embedding、EIU 提取模型、可选的轻量生成/问答模型

## 核心模块

| 模块 | 职责 | Demo 状态 |
|---|---|---|
| 文档接入模块 | 文件上传、MinIO 存储、元数据管理 | 已实现 |
| 文档解析模块 | 章节/段落/表格抽取、切块 | 已实现 |
| 向量化与索引模块 | BGE embedding、FAISS 索引 | 已实现 |
| 检索与问答模块 | 问题向量化、证据召回、结果组装 | 已实现 |
| 智能问答模块 | 对话式平台操作、In-Chat Preview | Demo 延后（仅占位） |
| 运行与任务模块 | 任务状态追踪、日志记录 | 已实现 |

## 数据流

1. 文件上传 → MinIO 存储 + MySQL 元数据
2. 文档解析 → 结构化块 + 原文定位
3. Embedding 生成 → FAISS 索引
4. 问题查询 → 向量召回 → 证据块组装 → 前端展示
5. （新增，延后）对话消息 → 意图解析 → 业务路由 → 结构化响应

## 评测集生成双模式

| 模式 | 输入 | 产出 | Demo |
|---|---|---|---|
| 文档→问答评测集 | 授信政策、财报等专业文档 | EIU + 标准答案 + 评测样本 | 已实现 |
