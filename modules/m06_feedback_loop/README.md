# 06 — 评测后数据回流

> 覆盖 BRD：9.（仅"评测后数据回流"部分）
> 平台边界：本平台**不涉及自动评测**——不运行待测系统、不计算检索 / 运行指标、不做失败归因与优化建议。平台与"评测"唯一的接口是：**允许外部评测完成后，将评测结果（条目级标注与原因）回流到本平台，由本平台据此修订问答对并生成新版本**。
> Demo 状态：回流功能 Demo 不做（后续版本）；自动评测体系不在本平台范围。

---

## 1. 平台边界：什么不做

以下能力属于"自动评测系统"，**不在本平台范围**：

- 待测系统适配器（向待测系统发问题、回收检索文段 / 答案）
- 检索指标（Recall@K / MRR / nDCG@K 等）与运行指标（P50/P95 耗时等）
- 失败归因引擎（D1–D8 归因、归因顺序）
- 优化建议 / Error Book / 防过拟合回归

本平台产出"可评测的问答对 / 知识点"，把它们交给外部评测系统去跑；评测系统跑完后的结果通过本平台的回流接口回传，平台只负责"接收 → 修订 → 新版本"。

---

## 2. 评测后回流需求

| 需求编号 | 需求 |
|---|---|
| FR-FB-001 | 回流入口：接收外部评测系统回传的条目级结果，至少含 case_id / intent_id、标注（可疑 / 打回 / 通过）、可选原因标签与备注 |
| FR-FB-002 | 回流工作台：按标注类型 / 优先级 / 来源 / 置信度等维度过滤排序，批量查看回流条目 |
| FR-FB-003 | 分流规则：被打回 / 可疑的条目进入"修题队列"，由人工或规则决定修订方式（改题 / 改答案 / 改证据 / 停用） |
| FR-FB-004 | 回流处理闭环：回流 → 标注 → 分流 → 处置（编辑走 FR-DS-EDIT）→ 重校验 → 新版本 → 关闭，全程留痕 |

> 说明：回流只解决"平台内问答对的修订"，不触发重新评测（重新评测由外部评测系统负责）；平台不保存或计算任何评测指标。

---

## 3. 回流数据模型

**evaluation_feedback 表：**

| 字段 | 类型 | 说明 |
|---|---|---|
| feedback_id | INT PK | |
| case_id | INT FK | 被回流的问答对 |
| intent_id | VARCHAR | 同 intent 共享，便于批量修订 |
| label | VARCHAR | suspicious / rejected / passed |
| reason_tag | VARCHAR | 可选原因标签（如答案错误 / 证据错位 / 歧义 / 超范围） |
| note | TEXT | 评测方备注 |
| source | VARCHAR | 外部评测系统标识 |
| confidence | FLOAT | 评测方给出置信度（可选） |
| handled_status | VARCHAR | pending / editing / resolved / closed |
| created_at | DATETIME | |

---

## 4. 回流处理闭环

```
外部评测系统回传结果
  → 写入 evaluation_feedback（pending）
  → 工作台按标注 / 优先级过滤
  → 分流到修题队列
  → 处置：编辑问答对（FR-DS-EDIT：改题 / 改答案 / 改证据 / 停用）
  → 自动触发重校验（质量校验）
  → 生成新版本草案（版本控制，见 05 §2）
  → 人工确认后冻结新版本
  → 标记 feedback closed
```

要点：
- 回流修订走统一的**版本控制**：每次修订产生新版本草案，原版本保留（见 05 §2）。
- 回流不要求"重新评测"；若需再评测，由外部系统重新拉取新版本导出集。
- 文档发生变化（覆盖更新）时，走覆盖式全量重算 + 新版本流程（见 05 §3.3），与回流共用版本控制机制。

---

## 5. 与版本控制 / 文档覆盖更新的协同

- **版本控制**：所有回流修订、手动编辑、文档覆盖更新都统一以"版本草案 → 冻结"管理，保证可追溯（见 05 §2）。
- **文档可覆盖更新（全量重算）**：新增或替换文档后，整体重解析重抽、旧文档数据作废、重新生成评测集（见 05 §3.3，覆盖式）。
- 回流闭环与文档覆盖更新互不耦合：回流只改问答对，文档更新只改 EIU 来源，二者最终都落到新版本快照。

---

## 6. 本平台不做的（重申）

- 不运行待测系统、不计算任何评测指标
- 不做失败归因（D1–D8）、不输出优化建议 / Error Book
- 不在平台内"重新评测"回流条目
